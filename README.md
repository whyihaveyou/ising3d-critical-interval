# Upper and lower bounds for the critical point of the three-dimensional Ising model

This repository contains the manuscript sources and the verification material for the theorem

```
275442362401406827838944754146320499627/178669509598593172161055245853679500373
    < exp(2 K_c) <
18874999999514449/11930000000000000
```

for the zero-field nearest-neighbour Ising ferromagnet on Z^3. In decimal form this is
`1.541630483120638 < exp(2 K_c) < 1.582145850755612`, i.e.
`0.2164203058063 < K_c < 0.2293910294998`.

## Layout

| Directory | Contents | Manuscript |
| --- | --- | --- |
| `manuscript/` | LaTeX sources, TikZ figures and their generator, `check_numbers.py` | all |
| `lower/` | prism integrals, half-edge allocations, suffix automaton and transfer bounds, with output logs | Sections 3–5 |
| `upper/` | physical rows, Green-function enclosures, multipliers, field-cap traversals at r_b = 3775/2386 and the interval extension | Sections 6–7 |
| `lean/` | Lean 4 modules for the chord moment, the prism allocation and the endpoint arithmetic | Appendix A.3 |

The programs keep the file names under which their outputs are quoted in Appendix A of the manuscript.

## Requirements

* Python 3 with the standard library (all arithmetic checks).
* A C++17 compiler (automaton and transfer bounds; `lower/STAGE53_PRISM_CHECK.py` calls `clang++`).
* NumPy, SciPy and GMP for the full ordered-side field traversals (`upper/new_endpoint/replay.py directed|raw`).
* `elan` with the toolchain in `lean/lean-toolchain` for the Lean replays.

## Quick checks (minutes)

```sh
python3 -B manuscript/check_numbers.py
(cd lower && python3 -B STAGE53_DISORDER_prism.py)
(cd lower && python3 -B STAGE54_CONTACT_verify.py)
(cd lower && python3 -B STAGE54_WEIGHTED_shapes.py)
(cd upper && python3 -B STAGE23_HOLDBACK_GREEN.py)
(cd upper/new_endpoint && python3 -B replay.py arithmetic)
python3 -B lean/STAGE57_certificate_replay.py
python3 -B lean/STAGE54_kinetic_replay.py
```

## Full recomputation

```sh
cd lower
python3 -B STAGE53_LOWER_AUDIT_verify.py --final-only
python3 -B STAGE53_PRISM_CHECK.py --cross-check
c++ -O3 -std=c++17 STAGE54_CONTACT_robust.cpp -o walk_check && ./walk_check 16 40 10000 9991
c++ -O3 -std=c++17 STAGE54_CONTACT_AUDIT.cpp -o walk_audit && ./walk_audit bulk
c++ -O3 -std=c++17 STAGE54_WEIGHTED_transfer.cpp -o shape_check && ./shape_check 16 28
c++ -O3 -std=c++17 STAGE42_DISORDER_PEER_saw.cpp -o saw_check && ./saw_check   # mu(Z^3) <= 4.73195
python3 -B verify_stage54_weighted_prism.py
cd ../upper/new_endpoint
python3 -B replay.py directed
python3 -B replay.py raw
```

See `upper/new_endpoint/RUN.md` for details of the ordered-side traversals.

## Building the manuscript

```sh
cd manuscript
latexmk -pdf main.tex
```

The figures in `manuscript/figures/fig_{prism,shapes,path,shells}.tex` are generated by `python3 make_figures.py` in that directory.
